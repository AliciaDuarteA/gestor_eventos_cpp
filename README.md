Gestor de Eventos
Programa en C++ orientado a objetos que permite agregar y listar eventos.

Cada evento contiene:
* Fecha
* Titulo

El proyecto utiliza:
* Clases en C++
* std::string
* std::unique_ptr
* std::vector
* std::cin
* std::cout

Compilar
make

Ejecutar
./main

Opciones
1. Agregar evento
2. Listar eventos
3. Salir
